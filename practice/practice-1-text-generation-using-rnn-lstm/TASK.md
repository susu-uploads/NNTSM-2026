В данной практической работе рассматривается полный цикл построения языковой модели для генерации текста.  В качестве данных используется набор русскоязычных новостных статей («Газета.Ru»).

Отдельно отмечается, что качество генерации в рамках данной практики будет ограниченным: используются модели небольшого размера, обученные на ограниченном объеме данных в течение малого числа эпох, а декодирование выполняется наиболее простым способом (greedy). Возникающие повторы и зацикливание в сгенерированном тексте являются ожидаемым результатом при таких условиях и не свидетельствуют об ошибке в реализации. Вопросы управления качеством генерации (стратегии декодирования) рассматриваются в следующей практической работе; в рамках данной работы основное внимание уделяется построению пайплайна и сравнению моделей по метрикам.

**Критерии оценивания**

***1 балл***выставляется за выполнение практической работы до ячейки с примером генерации лучшей модели включительно, включая реализацию Задания 1 (`WordTokenizer`) и Задания 2 (`SlidingWindowDataset`), проведение ключевого эксперимента и получение вывода генерации по лучшему run'у из MLflow. Необходимо быть готовым объяснить реализованный код и теоретическую часть обучения моделей.

***3 балла*** начисляются за выполнение Задания 3 («Влияние объема данных») и Задания 4 («Сравнение генерации») из раздела «Самостоятельная работа», засчитываемых совместно.

В качестве ответа необходимо прикрепить файл в формате .ipynb, названный по шаблону.

```
Например: 01-lstm_2026_ИУ7-11_Иванов.ipynb
```
